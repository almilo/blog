Most software keeps what an organisation knows in code, where only developers can
read it. This series tests a different idea: write the knowledge down as a model,
and derive the software from it. Each part tests the idea on a real source,
such as clinical guidance, a law or a popular diagram, and says how we would know
it is wrong.

Start with [part 1](/blog/software-that-knows-the-hypothesis/). The companion
posts go deeper into one part; you can read them or skip them.

- **Code:** [github.com/almilo/software-that-knows](https://github.com/almilo/software-that-knows)
